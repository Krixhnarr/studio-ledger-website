12A-112Install & set up

Up and running
in an afternoon.

Studio Ledger runs on each PC and keeps the studio’s records in one shared folder. Nothing is installed on the server: it only holds the folder.

S-01Server or NAS · once

Prepare the studio folder

  1. Create a shared folder every studio PC can reach, for example \\OFFICE-NAS\Studio. A file server, a NAS or an always-on office PC all work.
  2. Give each studio member read and write access to it.
  3. Keep the share to studio staff only. Roles are enforced inside the app, and the records are ordinary files in this folder.
  4. Turn on scheduled backups of the folder. Most NAS drives can do this for you.
S-02Principal’s PC · first

Create the studio

  1. Download the installer and run it. If Windows shows “Windows protected your PC”, choose More info → Run anyway.
  2. Open Studio Ledger, choose Set up a new studio and pick the shared folder. Enter the studio name and your name.
  3. In Team → Add person, add everyone, with their Windows username if you know it.
  4. Write your drawing rules in Standards, or start from the built-in set.
  5. Optional: connect AI review in Settings → Claude drawing review with your Anthropic API key and a monthly budget.
S-03Every other PC

Join the studio

  1. Install Studio Ledger the same way on each PC.
  2. Open it, choose Join your studio and pick the same shared folder.
  3. Pick your name from the list, or choose Request to join. The principal approves it in Team.
  4. That’s it. People are recognised by the account they sign in to Windows with, so there are no extra passwords.
S-04Principals & seniors · phone

The phone app

  1. A principal turns it on in Settings → Phone app and makes a one-time code for each principal and senior architect.
  2. Android: download the app on the phone and open it. Android asks once to allow installing apps from your browser; allow it.
  3. Open Studio Ledger on the phone, choose First time here, choose an email and password, and enter the code.
  4. See who's in, approve leave, review drawings and reply to the team from anywhere. Changes go through a PC in the office that has Studio Ledger open.

Before you start

Windows 10 or 11 (64-bit) on every PC, and a shared folder they can all open. Internet is needed only for AI review and Ask Claude.

After 30 days

Open Settings → Plan & billing, copy your Studio ID and email it to us with your plan. Paste the licence key you receive there, and every PC picks it up.

Updating

Download the new installer and run it on each PC. It installs over the old version; your records stay in the studio folder.

If a PC can’t connect

“Studio folder unreachable” in the sidebar means that PC can’t reach the share. Check the network, then open the folder path in File Explorer to confirm access.

13A-113Questions

Questions studios ask.

Does it need internet or a server?

No special server. Studio Ledger keeps everything in a shared folder: a NAS, a shared drive on one PC, or a synced drive all work. It works offline; only AI reviews and Ask Claude need internet.

What do I need for AI drawing review?

An Anthropic API key from console.anthropic.com, which the principal adds in Settings. You pay Anthropic directly for each check and set a monthly budget in Studio Ledger. A Claude Pro or Max chat subscription can't be used by other apps. Solo includes 10 AI checks a month; paid plans have no cap.

Which file types can be checked?

PDF. Export your sheets from AutoCAD, Revit, ArchiCAD or SketchUp Layout as PDF, as you would for issue. Paper size, sheet number, scale and title-block text are read straight from it.

What happens when the trial ends?

Choose a plan and paste the licence key. If you don't, Studio Ledger moves to the free Solo plan; a studio with more people or projects than Solo allows becomes read-only. Nothing is deleted, and a licence key unlocks everything again.

Do I pay per person?

No. Each plan includes a number of people (5, 15 or 30), with a lower price for every extra person on larger plans.

Is there a phone app?

Yes, for Android, for principals and senior architects: who's in and who's late, leave and drawings waiting on you, tasks, projects, fees, happiness, complaints and the studio's chats, with approvals from the phone. Juniors and interns use the desktop app. An iPhone app is on the way.

Is there a launch offer?

Yes. From 1 November 2026 to 31 January 2027, send us feedback from Settings → Launch feedback offer. If it would genuinely make Studio Ledger better, your studio gets a month of its plan free, once per firm. See all offers.

Does it work on Mac?

Not yet. Studio Ledger runs on Windows 10 and 11.
